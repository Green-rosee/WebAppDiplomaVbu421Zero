# WebAppDiplomaVbu421Zero

Учебный дипломный проект на ASP.NET Core .NET 10.

Проект представляет собой веб-приложение для выполнения инженерных расчётов,
подбора оборудования, расчёта трудоёмкости и стоимости,
а также хранения результатов расчётов в базе данных.

## Основные возможности

- Авторизация пользователей через JWT
- Разделение доступа по ролям
- Работа с несколькими функциональными областями ASP.NET Core Areas
- Расчёт параметров центробежных насосов
- Расчёт параметров якорных лебёдок
- Расчёт общей трудоёмкости
- Расчёт итоговой стоимости
- Сохранение выполненных расчётов
- Просмотр истории расчётов
- Интерактивные страницы на Blazor Interactive Server
- Работа с Excel-файлами
- Импорт исходных данных из Excel в базу данных
- Формирование и редактирование Excel-таблиц в браузере
- Работа с несколькими SQLite базами данных
- Валидация введённых данных через FluentValidation
- Контейнеризация приложения через Docker

## Структура проекта

Основное приложение находится в каталоге:

`WebAppEstimate`

В проекте используются ASP.NET Core Areas.

### SiteAdam

Область для работы с центробежными насосами.

Основные возможности:

- выбор серии насоса;
- подбор параметров насоса;
- расчёт трудоёмкости;
- расчёт стоимости;
- сохранение результатов;
- просмотр истории расчётов;
- отображение итоговых данных в интерактивной Excel-таблице;
- сохранение сформированных Excel-файлов.

### SiteBram

Область для работы с судовыми лебёдками.

На текущем этапе реализована якорная лебёдка.

Поддерживается:

- загрузка исходных данных из Excel;
- хранение серий лебёдок;
- хранение параметров массы;
- хранение параметров вала;
- хранение параметров цепи;
- формирование допустимых конфигураций якорной лебёдки;
- расчёт общей трудоёмкости;
- Blazor-страница расчёта якорной лебёдки.

В дальнейшем планируется добавить:

- швартовые лебёдки;
- буксирные лебёдки;
- грузовые лебёдки.

## Базы данных

В режиме разработки проект использует SQLite.

Основные базы данных:

- `dbSiteBase.sqlite` — пользователи и авторизация;
- `dbSiteAdam.sqlite` — данные центробежных насосов и история расчётов;
- `dbSiteBram.sqlite` — данные якорных и других судовых лебёдок.

Файлы баз данных не хранятся в GitHub и исключены через `.gitignore`.

Для каждой базы используется отдельный `DbContext`.

Регистрация контекстов вынесена в отдельный сервис:

`ServiceDatabaseRegistration`

## Работа с данными якорных лебёдок

Исходные данные для якорных лебёдок хранятся в Excel-файле и при необходимости
импортируются в `dbSiteBram.sqlite`.

Используются следующие наборы данных:

- `Series`
- `Weight`
- `Shaft`
- `Chain`
- `Design`

Таблица `Design` содержит допустимые комбинации:

`Series + Weight + Shaft + Chain`

Для идентификаторов сущностей используется `Guid`.

Для наследуемых сущностей лебёдок используется стратегия отображения
Entity Framework Core TPC (Table Per Concrete Type).

## Blazor

В проекте используется Blazor Interactive Server.

Общий корневой компонент находится в:

`WebAppEstimate/Components`

В нём располагаются:

- `App.razor`
- `Routes.razor`
- `_Imports.razor`

Blazor используется для интерактивных расчётных страниц,
где требуется изменение данных без полной перезагрузки страницы.

## Excel

Для работы с Excel используются две библиотеки.

### ClosedXML

Используется для:

- чтения исходных Excel-файлов;
- импорта данных в базу данных;
- серверного формирования Excel-документов.

### Syncfusion Blazor Spreadsheet

Используется для отображения и редактирования Excel-подобных таблиц
непосредственно в браузере.

## Авторизация

В проекте используется JWT-аутентификация.

JWT хранится в `HttpOnly` cookie:

`access_token`

Доступ к областям приложения ограничивается ролями.
