# WebAppDiplomaVbu421Zero

Учебный дипломный проект на ASP.NET Core .NET 10.

Проект представляет собой веб-приложение для выполнения инженерных расчётов
и хранения результатов расчётов в базе данных.

## Основные возможности

- Авторизация пользователей
- Разделение доступа по ролям
- Расчёт параметров центробежных насосов
- Расчёт общего количества часов
- Расчёт итоговой стоимости
- Сохранение выполненных расчётов
- Просмотр истории расчётов
- Работа с SQLite
- Валидация введённых данных через FluentValidation

## Используемые технологии

- ASP.NET Core .NET 10
- C#
- Entity Framework Core
- SQLite
- Razor Views
- Bootstrap
- FluentValidation
- Docker
- Docker Desktop / WSL2

## Структура проекта

Основное приложение находится в:

`WebAppEstimate`

В проекте используются Areas:

- `SiteAdam` — расчёты и работа с центробежными насосами
- `SiteBram` — дополнительный раздел приложения

## База данных

Проект использует SQLite.

Основные базы данных:

- `dbSiteBase.sqlite` — авторизация и пользователи
- `dbSiteAdam.sqlite` — данные и история расчётов

Файлы базы данных не хранятся в GitHub и исключены через `.gitignore`.
